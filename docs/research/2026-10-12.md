# Реализация и проверка 12 октября 2026

## Результат

Без BMAD создано Django-приложение: браузерный кабинет с логином/паролем, Telegram-бот, административные экраны с TOTP, ручное управление подписками, очередь операций/уведомлений, импорт 3x-ui и шифрованные резервные копии. Переводы денег остаются вне системы; решение о продлении принимает владелец.

Развёрнуты локальные Docker-сервисы web, worker, bot и PostgreSQL. HTTP доступен на `127.0.0.1:8000`, PostgreSQL — `127.0.0.1:15432`. Бот @hope2vpnbot проверен через getMe; webhook отсутствует. Предыдущая демонстрационная база `hope` сохранена; действующая интеграция использует собственную базу `hope_live`.

В базе приложения 33 подписки, один локальный владелец, ноль операций изменения панели. Импорт не назначает клиентов пользователям автоматически. Владелец проверяет получателя по прежнему контакту и выдаёт приглашение; пользователь задаёт логин/пароль. Привязка Telegram требует подтверждения в боте и исходной браузерной сессии. Поле tgId панели не меняется.

## Секреты и восстановление

`.env` имеет права 0600, исключён из Git и Docker image. Предыдущие варианты окружения сохранены локально в игнорируемой data с такими же правами. Значения секретов, имена клиентов, UUID/subId и адреса частной панели в этот отчёт не включены.

Начальная зашифрованная копия базы приложения сохранена в `data/hope-live-initial.enc`. Ключ DATA_ENCRYPTION_KEY нужно хранить отдельно. Сценарий восстановления проверен в тестовой среде; он отзывает сессии/токены и останавливает записи до сверки. Команды обслуживания — [operations.md](../operations.md).

## Границы локального запуска

Localhost доступен только на этом компьютере: для кабинета на телефоне нужен доступный адрес и соответствующие hosts/origins, для публичного размещения — HTTPS и production-настройки. Доступность без VPN в сетях операторов, импорт на реальных телефонах, работа туннеля и применение изменений действующей панелью не подтверждаются этими проверками. Их проверяют отдельно на выделенном тестовом клиенте перед включением записи.
