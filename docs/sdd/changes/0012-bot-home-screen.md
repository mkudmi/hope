# 0012 — Возврат на стартовый экран бота

Статус: verified (автотесты; ручной чат отдельно). Создано: 2026-10-12. Обновлено: 2026-10-12.
Связанные требования: R-15, R-16. Решения: не требуются.

## Проблема и результат

После /start новый пользователь видит приветствие, а возврат «Главное меню»
показывает другую страницу «Выберите действие». Пользователь просит одинаковую
главную страницу при первом входе и при возврате из разделов.

## Объём и требования

- Единая функция формирует стартовый текст и клавиатуру по текущей привязке.
- Без привязки: прежнее приветствие, тарифы, новое подключение, существующая
  подписка, заказы и помощь. Со связью: прежний стартовый экран подписки.
- /start и callback menu используют один экран; menu редактирует сообщение.
- Текущее состояние привязки проверяется при возврате, а не запоминается навсегда.
- Токены /start, поддержка, заказы и уведомления сохраняют прежние правила.

## Критерии приёмки

- AC-01: /start → тарифы → menu возвращает тот же текст и клавиатуру без связи.
- AC-02: связанный пользователь возвращается на свой стартовый экран.
- AC-03: изменение/удаление связи между переходами отражается при возврате.
- AC-04: возврат использует editMessageText без нового sendMessage.

## Решение и влияние

core/bot.py: общий home_screen. tests/test_bot_navigation.py: сравнение первого
экрана и возврата, переходы состояния. Миграции/настройки не нужны; панель не
изменяется. Откат — прежний код bot и пересборка только этого контейнера.
