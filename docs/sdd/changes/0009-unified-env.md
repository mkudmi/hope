# 0009 — Единый файл настроек

Статус: verified. Дата: 2026-10-12. Требование R-12.

Все поддерживаемые пользовательские настройки приложения, Telegram, панели, тарификации, локальной БД/аккаунтов и browser smoke перечислить в одном .env.example с русскими пояснениями. Действующий .env привести к тому же порядку, сохраняя точные внесённые значения и необъявленные параметры. Отсутствующие параметры добавить с безопасными значениями; SECURE_SSL_REDIRECT сохранить эквивалентным текущему DEBUG. Секреты не выводить, не менять и не коммитить; файл 0600, резервная копия в игнорируемом data/. Runtime-переменные Django/контейнеров и внутренние константы не объявлять как новые пользовательские настройки.

Проверка: покрытие используемых getenv/flag, сохранение значений, Django check, compose validation без вывода конфигурации. Не запускать smoke, не менять реальную панель, базы или пароль администратора. Новые комментарии не требуют перезапуска сервисов; конфигурация контейнеров имеет приоритет над .env для DATABASE_URL.

## Результат

Единый .env.example содержит 35 настроек с пояснениями; текущий .env приведён к нему, 31 ранее внесённое значение сохранено побайтно на уровне значений. Четыре отсутствующих параметра добавлены, режим редиректа эквивалентен DEBUG. Резервная копия data/env-before-unified.env и .env имеют 0600; оба исключены Git. Статическая сверка getenv/flag и динамических имён не обнаружила отсутствующих настроек. Django check и docker compose --profile telegram config --quiet успешны. Приложение/БД/панель не менялись, службы не пересоздавались; новые поля служат явным описанием прежнего поведения. Для фактических будущих изменений env нужно пересоздать затронутые контейнеры.
