# 0003 — Кабинет на домене панели по /hope/

Статус: verified. Создано: 2026-10-12. Обновлено: 2026-10-12.
Связанные требования: R-01, R-09, R-11, R-14. Решение: [ADR 0001](../decisions/0001-shared-origin.md).

## Требование

Пользователь указал общий домен с действующей панелью и подтвердил путь `/hope/` для кабинета. Текущие адреса панели/API/выдачи подписок остаются прежними. Локальная разработка сохраняет корневой localhost SITE_URL до размещения на сервере.

## Решение и критерии

- AC-01: префикс определяется по пути SITE_URL; reverse, redirect, ссылки форм, static и бот используют его без двойного добавления. URL без пути продолжает работать.
- AC-02: cookies имеют собственные имена HOPE и область пути кабинета. Это уменьшает коллизии с панелью, но общий origin не даёт полноценной изоляции приложений.
- AC-03: пример Nginx добавляет только /hope/ в существующий HTTPS server и снимает префикс перед передачей loopback upstream. Панельные location не заменяются; proxy должен явно перезаписывать заголовок HTTPS, доверие к нему включается отдельной настройкой.
- AC-04: конфигурация production документирована без приватных адресов/секретов; SITE_URL согласован с ALLOWED_HOSTS/CSRF_TRUSTED_ORIGINS. Локальная .env и действующий сервер не меняются.
- AC-05: тесты проверяют login redirect, формы/CSRF, static, cookies, ссылки приглашений и бота под префиксом. Публичный домен и реальные сети не считаются проверенными локальными тестами.

Отдельные домены дали бы изоляцию origin, но выбранный владельцем общий домен сохраняется. Перед реальным размещением нужно проверить, что панель или выдача подписок не используют /hope/; никаких замен текущей конфигурации в этой задаче.

## Проверки и ограничения

| Критерий | Проверка | Результат |
|---|---|---|
| AC-01, AC-05 | tests/test_shared_domain.py, включая настоящий WSGIHandler и статические ресурсы | 6 целевых тестов прошли |
| AC-02 | Cookie names/path, login/logout, CSRF POST под префиксом | выполнено |
| AC-03 | Сверка фрагмента Nginx с контрактом WSGI/WhiteNoise; docker compose config --quiet | фрагмент подготовлен, compose корректен; nginx -t на целевом сервере не выполнялся |
| AC-04 | .env не менялась; публичные примеры только vpn.example.com; документация/ADR | выполнено |

Полный набор на отдельной PostgreSQL: **97 passed** (8.17 s). Ruff и Django check прошли. Отдельный запуск settings с SITE_URL=https://vpn.example.com/hope подтвердил prefix/static/cookie scope. Первые тесты с Django Client требовали явного set_script_prefix: Client обходит WSGIHandler.__call__; добавлена корректная подготовка и самостоятельная проверка реального WSGI handler.

Изменяется приложение и добавляется пример конфигурации, удалённое развёртывание не выполняется. Verified относится к поддержке префикса/локальным тестам, а не готовности публичного адреса. Не проверялись целевой Nginx, сертификат, доступность операторам или пользовательский VPN. Имена cookies меняются: ранее открытые сессии потребуют повторного входа.

Локальные сервисы пересобраны; браузерная проверка текущего root localhost подтвердила login/CSRF, cookies HOPE и logout. Публичный префикс локальной .env не включался; запись панели false, реальных операций 0.
