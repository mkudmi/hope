# 0006 — Комментарии клиентов из панели

Статус: verified. Дата: 2026-10-12. Требование: R-02.

Администратор узнаёт клиентов по comment в 3x-ui. Read-only API действующей панели подтвердил это поле: 33 записи, 31 непустой комментарий, содержимое не выводилось.

Критерии:
- Импорт и успешная сверка сохраняют актуальный comment отдельно от локальной метки; повторный импорт обновляет и очищает удалённый комментарий.
- В административной таблице есть колонка «Комментарий из панели», в карточке — то же поле; пустое значение обозначено тире, текст HTML экранируется, длинные строки переносятся.
- Поиск включает комментарий; пользовательские страницы и Telegram не показывают его.
- Локальные метки, аккаунты, Telegram, идентификаторы и VPN-настройки не меняются. Проверки конфликтов сохраняются, панель остаётся read-only.

Реализация: отдельный TextField Subscription.panel_comment, штатная миграция, record_observation, staff search и шаблоны. Перед миграцией — зашифрованный бэкап собственной БД HOPE; затем повторный read-only импорт. Комментарии — приватные данные администратора, не использовать для подтверждения владения и не включать в логи/скриншоты.

## Проверки

- tests/test_panel_comments.py: обновление/очистка комментария, сохранение локальной метки/владельца, отсутствие записей через API, отсутствующие/null/нестроковые значения, административный поиск/HTML-экранирование и приватность.
- Полный набор на отдельной PostgreSQL: 132 passed за 9.16s; ruff, Django check, makemigrations --check успешны.
- Изолированный браузер с временной SQLite: таблица/карточка, длинный многострочный комментарий, ширины 320/390/1280 без переполнения страницы и ошибок JS.
- Перед миграцией сохранён зашифрованный бэкап своей HOPE DB data/hope-before-panel-comments.enc (0600); локальные Docker-образы обновлены. Реальная панель только читается.

Локальная миграция 0005 применена, повторный read-only импорт завершён без новых записей: 33 подписки, 31 непустой комментарий. Health OK, операций 0, PANEL_WRITES_ENABLED=false. Содержимое реальных комментариев не печаталось; панельные настройки не изменены.
