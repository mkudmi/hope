# 0019 — Создать production администратора HOPE

Статус: verified (Czech production DB). Создано: 2026-10-13. Обновлено: 2026-10-13.
Связанные требования: R-22, R-17. Решения: не требуются.

## Проблема и результат

Пользователь попросил создать администратора HOPE на production с теми же логином и паролем, что у действующего локального администратора.

## Объём и требования

- Локальные credentials брать из окружения работающего локального web, проверить логин и password hash локальной записи, пароль не выводить и не сохранять в Git.
- До записи подтвердить, что production target — отдельная Czech HOPE DB, целевой логин отсутствует и лишних superuser нет.
- Создать production superuser штатным Django user model; не менять локальную базу, подписки, очередь, 3x-ui и runtime сервисы.
- Не выводить пароль в логи/командные аргументы; передать одноразово по SSH stdin.
- Вход приложения требует TOTP; пользователь при первом входе завершает enrollment в браузере.

## Критерии приёмки

- AC-01: production создаёт отсутствующего superuser с тем же нормализованным логином.
- AC-02: переданный пароль совпадает с локальным credential; plaintext и TOTP secret не сохраняются/не выводятся.
- AC-03: вход `/hope/staff/` остаётся защищённым, production web/bot/worker не перезапускаются.

## Решение и влияние

Создать `core.User` с `is_staff=True`, `is_superuser=True`, активным аккаунтом и паролем, полученным из локального web-окружения. Перед созданием проверить уникальность username повторно внутри DB-транзакции. Panel 3x-ui не вызывается.

## Проверки и прослеживаемость

| Критерий / требование | Код / документ | Проверка и среда | Фактический результат |
|---|---|---|---|
| AC-01 / R-22 | Production Django User | Czech production DB | Создан отсутствовавший активный superuser `admin` с `is_staff=True`, `is_superuser=True` |
| AC-02 / R-22 | Django password hash | Проверка локального пароля через `check_password` в обеих DB | Совпадает; plaintext не печатался и не сохранялся в репозитории. TOTP пока не настроен. |
| AC-03 / R-17 | `/hope/staff/`, service state | GET production admin route и Docker inspect | `/hope/staff/` требует вход; web healthy, bot/worker запущены. Сервисы не перезапускались. |

## Итог и ограничения

Пароль повторяет локальный admin password по просьбе пользователя. Перед входом завершить обязательную настройку TOTP. Provisioning не подтверждает корректность фактического входа через browser form.
