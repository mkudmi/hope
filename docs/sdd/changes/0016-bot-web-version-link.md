# 0016 — Ссылка на веб-версию из стартового экрана

Статус: verified (локальная сборка; чат не проверялся). Создано: 2026-10-13. Обновлено: 2026-10-13.
Связанные требования: R-14, R-21. Решения: не требуются.

## Проблема и результат

На стартовом экране бота нет прямого перехода к веб-версии приложения. Добавить
отдельную URL-кнопку входа.

## Объём и требования

- На стартовом экране непривязанного пользователя показать кнопку «Веб версия».
- Кнопка открывает страницу `/login/` относительно базового `SITE_URL`, включая
  настроенный префикс сайта (например, `/hope/`).
- Не менять `.env`, домен, привязку Telegram или бизнес-сценарии входа.
- Ссылка выполняется Telegram-клиентом, callback не создаётся.

## Критерии приёмки

- AC-01: стартовая клавиатура содержит URL-кнопку «Веб версия».
- AC-02: URL равен `SITE_URL + "/login/"` и сохраняет путь-префикс из `SITE_URL`.
- AC-03: остальные стартовые кнопки и callbacks не меняются.
- AC-04: действие описано в UC-B048, индексе и INVENTORY.

## Решение и влияние

Добавить URL-кнопку в клавиатуру непривязанного главного экрана `home_screen` в
`core/bot.py`. Существующий callback браузерного кабинета привязанных
пользователей остаётся без изменений. Миграции, настройки и панель не нужны.

## Итог и ограничения

Ссылка строится из текущего `SITE_URL`. Локальный `SITE_URL` сейчас указывает на
loopback `127.0.0.1`, поэтому такая ссылка доступна только на устройстве,
которое видит этот адрес; `.env` не меняется.
