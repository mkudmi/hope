# 0021 — Оставить одну кнопку браузерного кабинета в меню

Статус: verified (CI + Czech production). Создано: 2026-10-13. Обновлено: 2026-10-13.
Связанные требования: R-24, R-21. Решения: не требуются.

## Проблема и результат

На главном экране связанного пользователя видны две кнопки веб-кабинета: callback «Браузерный кабинет» и URL «Открыть сайт». Оставить одну прямую URL-кнопку.

## Объём и требования

- В `menu()` убрать callback-кнопку «Браузерный кабинет».
- Сохранить URL-кнопку «Открыть сайт ↗», ведущую на `SITE_URL + /login/`.
- Не менять другие пункты меню, URL/префикс сайта и обработчик `/account` для onboard/кабинета.
- Старые клавиатуры с callback `portal` продолжают обрабатываться прежним кодом.

## Критерии приёмки

- AC-01: пользователи с привязкой и без неё видят в главном меню ровно одну ссылку на веб-кабинет — URL-кнопку «Открыть сайт ↗».
- AC-02: тарифы, подключение, подписка, продление, заказы и помощь остаются без изменений.
- AC-03: адрес ссылки сохраняет `SITE_URL` и `/login/`; команда `/account` и старые callback-сообщения продолжают работать.

## Решение и влияние

Удалить только callback-ряд `portal` из `menu()`. URL-кнопка уже открывает ту же форму входа. Не удалять callback-handler и `/account`: ими пользуются onboarding и прежние сообщения.

Новые экраны содержат одну URL-кнопку; уже отправленные Telegram-сообщения не изменяются автоматически. Пользователю нужно отправить `/start` или нажать «Главное меню», чтобы получить обновлённую клавиатуру. Callback продолжает работать в старых сообщениях.
