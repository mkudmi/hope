# 0003 — GitHub Actions и отдельные SSH-релизы HOPE

Статус: accepted. Дата: 2026-10-12. Связь: [0013](../changes/0013-github-cz-deployment.md).

## Контекст

На сервере Чехии работает действующая VPN-панель. Нужна раскатка HOPE через
GitHub, без передачи секретов приложения в публичный репозиторий и без общего
перезапуска Docker или VPN.

## Решение

Hosted runner передаёт архив точного SHA через SSH с проверенным host key.
Ключ допускает только forced command приёмника HOPE. Релизы — /opt/hope/releases,
общая .env — /opt/hope/shared/.env. Compose project hope-cz имеет собственную БД
и loopback web. Workflow сериализуется concurrency, сервер — flock.

## Последствия и альтернативы

Не нужен постоянный self-hosted runner на VPN-сервере. Сервер собирает небольшой
Docker-образ; запас RAM/диска проверен, нагрузка сборки требует наблюдения.
Docker-деплой всё равно доверяет коду main: права записи репозитория являются
правами на запуск кода HOPE. Ключ не даёт произвольный shell/port forwarding.
Нельзя откатить схему БД простым переключением релиза. Registry/GHCR добавил бы
учётные данные сервера для pull; для текущего масштаба выбран SSH-архив.
