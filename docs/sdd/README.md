# SDD проекта HOPE VPN

SDD = Specification-Driven Development: сначала описываем проверяемое поведение, затем реализуем и фиксируем доказательства. Работа ведётся без BMAD. Правила для агентов находятся в [AGENTS.md](../../AGENTS.md).

## Источники и назначение документов

- [SPEC.md](SPEC.md) — текущие обязательные требования со стабильными ID и карта проверок.
- [Use cases кнопок](../use-cases/README.md) — отдельные сценарии бота, кабинета и админки с [картой элементов](../use-cases/INVENTORY.md).
- `changes/` — спецификации отдельных изменений, их решения, проверки и остаточные ограничения; [шаблон](templates/change.md).
- `decisions/` — значимые архитектурные решения. Номер независим от номера изменения; ссылки связывают их.
- [product.md](../product.md) — подробные пользовательские сценарии и варианты; не все предложения реализованы.
- [architecture.md](../architecture.md) — архитектура и концептуальная модель; фактическая карта кода — в AGENTS.
- [launch.md](../launch.md) — перенос и условия публичного запуска.
- [operations.md](../operations.md) — актуальные команды и обслуживание.
- [research/](../research/2026-10-12.md) — исторические результаты исследований/запусков, с датой и средой.

При противоречии приоритет имеют прямые указания пользователя. Расхождение между SPEC, кодом и подробными документами нужно разрешить и зафиксировать, а не выбрать удобный вариант молча.

## Процесс и статусы

`draft` → `ready` → `implementing` → `verified`; `blocked` — есть конкретное препятствие, `superseded` — замена со ссылкой. Ready означает достаточную ясность для реализации, а не требование новой пользовательской подписи. В одной задаче можно пройти несколько статусов. Даты пишутся в ISO-формате.

Имя изменения: следующий свободный четырёхзначный номер и короткое имя, например `0002-subscription-filter.md`. Перед созданием проверить каталог. Критерии описывают наблюдаемое поведение, проверки называют среду и фактический результат. Для значимого решения достаточно короткого ADR с контекстом, выбором, последствиями и альтернативами.
