# UC-A022 — Выдать приглашение

Дата сверки: 2026-10-12. Статус: описана текущая реализация.

## Участник и триггер

**Участник:** Администратор HOPE VPN.  
**Кнопка / действие:** Выдать приглашение.

## Предусловия

У подписки нет владельца; она не исключена; прежний контакт проверен.

Для административных действий обязательны активная staff-сессия и актуальный TOTP; POST защищён CSRF. PANEL_MODE=real и PANEL_WRITES_ENABLED=false сохраняются: разработка не разрешает панельную запись.

## Основной сценарий

1. Отметить проверку владельца.
2. Нажать кнопку.
3. Сервис отзывает прежние приглашения и создаёт одноразовый токен на 72 часа.
4. Передать показанную ссылку лично проверенному клиенту.

## Результат и побочные эффекты

Подготовлено приглашение на конкретную подписку.

Группа узнаёт факт создания, сама ссылка в группу не направляется.

## Альтернативы и ошибки

Нет галочки/подписка уже активирована/исключена: отказ.

## Критерии приёмки

- С правильными предусловиями нажатие приводит к описанному результату.
- Альтернативы и отказ не приводят к неописанной смене срока, владельца или Telegram-привязки.
- Проверить основной сценарий и перечисленные ошибки на тестовых данных; персональные секреты не включать в отчёты.

Критерии выше — план проверки этого UC. В данной задаче сверяется документация; новый прогон продуктовых тестов по каждому UC не заявляется. Связанные существующие проверки: [карта требований SDD](../../sdd/SPEC.md).
