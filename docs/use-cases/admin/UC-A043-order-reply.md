# UC-A043 — Отправить сообщение клиенту

Дата: 2026-10-13. Статус: подготовлено, не развёрнуто.

## Предусловия

Staff, MFA/доверенный браузер и CSRF; открыта карточка заказа. Текст ручного ответа до 2000 символов, действителен reply_id.

## Основной сценарий

1. Вручную написать ответ или реквизиты.
2. Нажать «Отправить сообщение клиенту».
3. Создать OrderMessage и личное уведомление с ключом reply_id.
4. Клиент прочитает ответ в карточке заказа; при доступном Telegram получит его лично.

## Результат и ограничения

Без Telegram сообщение всё равно доступно в кабинете. Повторный POST не создаёт дубль; содержимое не зеркалируется группе. Отправка реквизитов сама не подтверждает перевод и не продлевает доступ.
