# UC-A020 — Импортировать из панели

Дата сверки: 2026-10-13. Статус: автоматический запуск подготовлен в коде; выкладка отложена.

## Участник и триггер

**Участник:** Администратор HOPE VPN.  
**Кнопка / действие:** Импортировать из панели; автоматический запуск после нового административного входа.

## Предусловия

Администратор; настроен read-only доступ API.

Для административных действий обязательны активная staff-сессия и актуальная MFA
(TOTP либо доверенный браузер); POST защищён CSRF. Импорт использует только чтение
панели независимо от режима разрешённых штатных записей.

## Основной сценарий

1. Завершить новый вход администратора либо нажать ручную кнопку.
2. Сервис читает список и карточки панели.
3. Идемпотентно создаёт/обновляет локальные снимки и комментарии допустимых записей.
4. Проверяет идентичность и конфликты.
5. Показывает число новых записей.

## Результат и побочные эффекты

Локальные сведения обновлены; панель не изменена.

Группа получает итог импорта; комментарий не подтверждает владельца.

Автоматическая попытка выполняется один раз на новый вход после MFA. Обновление
страниц и повторная MFA той же сессии её не повторяют. До MFA и при клиентском
входе импорт не запускается. Новый парольный вход начинает новую попытку.

## Альтернативы и ошибки

Сеть/API/неизвестный контракт: ошибка; исключённые записи пропускаются; дубликаты subId/несогласованное managed-состояние требуют разбора.

Ошибка автоматического импорта не отменяет вход. Показать ошибку; для повторной
попытки администратор использует ручную кнопку.

## Критерии приёмки

- С правильными предусловиями нажатие приводит к описанному результату.
- Альтернативы и отказ не приводят к неописанной смене срока, владельца или Telegram-привязки.
- Проверить основной сценарий и перечисленные ошибки на тестовых данных; персональные секреты не включать в отчёты.

Автоматический запуск и ручной повтор после ошибки проверены в изолированных
тестах `tests/test_admin_login_import.py`; real-панель не вызывалась. Полные
результаты и ограничения — [SDD 0024](../../sdd/changes/0024-auto-import-on-admin-login.md).
