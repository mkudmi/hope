# UC-A054 — Перевод проверен — продлить из Telegram

Дата: 2026-10-13. Статус: подготовлено, не развёрнуто.

## Предусловия

Свой действительный Telegram предпросмотр; поступление денег проверено человеком.

## Основной сценарий

1. Нажать финальную кнопку.
2. Сервис атомарно подтверждает оплату и создаёт штатную renewal Operation.
3. Worker проверяет применение; заказ становится fulfilled после verified.

## Результат и ограничения

Повтор не продлевает второй раз. Чужой, устаревший, изменённый или межканальный approval отклоняется. Write-off/конфликт/ошибка preparation откатывают совмещённое подтверждение.
