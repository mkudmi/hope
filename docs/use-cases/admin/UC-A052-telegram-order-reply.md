# UC-A052 — Ответить клиенту из админского Telegram чата

Дата: 2026-10-13. Статус: подготовлено, не развёрнуто.

## Предусловия

Числовой отправитель в ADMIN_TELEGRAM_USER_IDS; правильный чат; активный ADMIN_TELEGRAM_LOGIN.

## Основной сценарий

1. Ответить текстом на доставленное уведомление бота о заказе.
2. Сервис находит заказ по сохранённому chat_id/message_id.
3. Сохраняет OrderMessage и персональный Notice.

## Результат и ограничения

Текст до 2000 символов. Повтор одного Telegram сообщения не создаёт дубль. Чужой чат/ID, anonymous sender и неизвестная цитата отклоняются. Реквизиты вводятся человеком.

Критерии и фактические результаты — [SDD 0027](../../sdd/changes/0027-web-renewal-and-telegram-admin.md), `tests/test_web_renewal.py`. Реальная доставка/панель не проверяются этим изолированным запуском.
