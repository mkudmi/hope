# UC-A056 — Перевод проверен — продлить из веба

Дата: 2026-10-13. Статус: подготовлено, не развёрнуто.

## Предусловия

Свой действительный web approval, актуальная staff/MFA сессия, CSRF.

## Основной сценарий

1. Нажать финальное подтверждение.
2. В одной транзакции подтвердить оплату и поставить продление в очередь.
3. Сообщить готовность после verified.

## Результат и ограничения

Прежние VPN-поля/квоты сохраняются. Повтор, изменение версии/владельца/условий заказа и истечение предпросмотра не дают второе продление.

Критерии и фактические результаты — [SDD 0027](../../sdd/changes/0027-web-renewal-and-telegram-admin.md), `tests/test_web_renewal.py`. Реальная доставка/панель не проверяются этим изолированным запуском.
