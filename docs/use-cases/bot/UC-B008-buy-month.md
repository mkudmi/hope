# UC-B008 — 1 месяц — оформить заказ

Дата сверки: 2026-10-12. Статус: описана текущая реализация.

## Участник и триггер

**Участник:** Пользователь Telegram.  
**Кнопка / действие:** Оформить заказ; buy:month:<подпись предложения>.

## Предусловия

Открыто действительное предложение; личный чат.

Действия с аккаунтом выполняются в личном чате; callback ограничены по частоте. Сбой Telegram-доставки не отменяет сохранённую заявку/заказ.

## Основной сценарий

1. Нажать «Оформить заказ» для 1 месяц.
2. Сервис проверяет подпись и актуальную цену.
3. Под блокировкой контакта сохраняет заказ либо возвращает существующий активный.
4. Бот показывает ожидание реквизитов от администратора лично.

## Результат и побочные эффекты

Заказ сохраняет цену 299 ₽ и длительность; доступ ещё не создан.

Новый заказ создаёт событие админской группе через outbox. Ни реквизиты, ни панельные изменения автоматически не отправляются.

## Альтернативы и ошибки

Устаревшая подпись/каталог: отказ и новый выбор. Один активный заказ на контакт; повтор не создаёт второй. При write-off бот предупреждает об ожидании владельца.

## Критерии приёмки

- С правильными предусловиями нажатие приводит к описанному результату.
- Альтернативы и отказ не приводят к неописанной смене срока, владельца или Telegram-привязки.
- Проверить основной сценарий и перечисленные ошибки на тестовых данных; персональные секреты не включать в отчёты.

Критерии выше — план проверки этого UC. В данной задаче сверяется документация; новый прогон продуктовых тестов по каждому UC не заявляется. Связанные существующие проверки: [карта требований SDD](../../sdd/SPEC.md).
