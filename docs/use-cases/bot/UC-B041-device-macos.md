# UC-B041 — Выбрать macOS

Дата сверки: 2026-10-12. Статус: описана текущая реализация.

## Участник и триггер

**Участник:** Пользователь Telegram.  
**Кнопка / действие:** macOS; ← Выбрать приложение (для macOS); device:macos.

## Предусловия

Собственная подписка с персональной ссылкой; личный чат.

Действия с аккаунтом выполняются в личном чате; callback ограничены по частоте. Сбой Telegram-доставки не отменяет сохранённую заявку/заказ.

## Основной сценарий

1. Нажать «macOS».
2. Бот показывает Happ и INCY для выбранного устройства.
3. Выбрать приложение.

## Результат и побочные эффекты

Открыт выбор клиента для macOS.

Записей в панель нет.

Неверная платформа отклоняется; доступность магазинов/установки зависит от устройства.
