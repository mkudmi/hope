# UC-B048 — Открыть веб-версию

Дата сверки: 2026-10-13. Статус: описана текущая реализация.

## Участник и триггер

**Участник:** Пользователь Telegram без привязанного аккаунта.  
**Кнопка / действие:** 🌐 Веб версия.

## Предусловия

Личный чат с ботом, открыт стартовый экран. `SITE_URL` настроен для текущего
окружения.

## Основной сценарий

1. Нажать «Веб версия».
2. Telegram открывает `SITE_URL + "/login/"` в браузере, сохраняя префикс из
   базового URL, например `/hope/`.

## Результат и побочные эффекты

Открывается форма входа веб-приложения. Telegram-привязка и подписка не меняются;
кнопка не вызывает callback бота.

В локальном окружении `SITE_URL` может указывать на `127.0.0.1`, доступный только
с устройства, на котором запущено приложение.

## Альтернативы и ошибки

Недоступность адреса или страницы входа обрабатывается браузером. Кнопка не
создаёт заявку и не отправляет сообщение.

## Критерии приёмки

- Кнопка отображается на стартовом экране.
- URL открывает страницу входа, сформированную из `SITE_URL`.
