# UC-W041 — Отменить веб-заказ

Дата: 2026-10-13. Статус: подготовлено, не развёрнуто.

## Предусловия

Собственный заказ awaiting_payment; CSRF.

## Основной сценарий

1. Нажать «Отменить заказ».
2. Сохранить cancelled; допускается новый заказ.

## Результат и ограничения

После заявления об оплате отмена недоступна; обращение решает владелец.
