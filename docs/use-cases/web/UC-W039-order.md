# UC-W039 — Карточка своего заказа

Дата: 2026-10-13. Статус: подготовлено, не развёрнуто.

## Предусловия

Вошедший владелец заказа.

## Основной сценарий

1. Открыть карточку заказа.
2. Увидеть сохранённые цену/срок, статус и ручные сообщения администратора.

## Результат и ограничения

Пока вкладка видима, изменение статуса/переписки проверяется раз в 10 секунд и карточка обновляется; во время отправки формы автоперезагрузка отключена. Чужая карточка и updates endpoint возвращают 404; реквизиты/переписка не зеркалируются другим клиентам.

## Проверки

Критерии и фактические результаты — [SDD 0027](../../sdd/changes/0027-web-renewal-and-telegram-admin.md), `tests/test_web_renewal.py`. Реальная доставка/панель не проверяются этим изолированным запуском.
