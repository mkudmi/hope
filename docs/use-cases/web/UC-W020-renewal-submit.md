# UC-W020 — Выбрать срок и отправить запрос на продление

Дата: 2026-10-13. Статус: подготовлено, не развёрнуто.

## Предусловия

Клиент вошёл в собственный кабинет и имеет подписку; тарифы утверждены. Telegram необязателен. POST защищён CSRF.

## Основной сценарий

1. Открыть продление и выбрать 7 дней, 1/3/6/12 месяцев с полной ценой.
2. Нажать «Отправить запрос на продление».
3. Сохранить собственный web PurchaseOrder с фиксированными условиями и уведомить админский чат.
4. Открыть карточку заказа, дождаться ручного ответа администратора с реквизитами.
5. После перевода нажать «Я оплатил»; дождаться ручного подтверждения и проверки worker.

## Результат и ошибки

Один активный заказ на аккаунт; оформление не меняет срок и не подтверждает деньги. Устаревшие цены отклоняются. Чужая подписка/неактивный/staff аккаунт не используются. При повторе возвращается активный заказ из любого интерфейса.
