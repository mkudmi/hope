# UC-W021 — Экстренный доступ на час

Дата сверки: 2026-10-12. Статус: описана текущая реализация.

## Участник и триггер

**Участник:** Гость или клиент HOPE VPN.  
**Кнопка / действие:** Экстренный доступ на час.

## Предусловия

Истекшая фиксированная управляемая verified-подписка; включённая запись, доступ enable=true, без блокировки/исчерпанной квоты/конфликта.

POST проверяет CSRF; защищённые страницы требуют собственной активной сессии. Пути получают префикс /hope/ при соответствующем SITE_URL; локально используется корень localhost.

## Основной сценарий

1. Нажать активную кнопку.
2. Сервис повторно проверяет условия под row lock.
3. Проверяет 3 часа с предыдущего принятого запроса и максимум 8 за сутки МСК.
4. Создаёт идемпотентную операцию на час от принятия запроса.
5. Worker проверяет применение.

## Результат и побочные эффекты

Час временного доступа считается с принятия; готовность только после verified.

Квота/блокировки не сбрасываются, деньги не подтверждаются; группа получает события операции.

## Альтернативы и ошибки

Сейчас PANEL_WRITES_ENABLED=false: кнопка отключена. Cooldown сохраняется через полночь; ошибка/дубликат не даёт второй час; если час истёк до первой записи, операция завершается без записи.

## Критерии приёмки

- С правильными предусловиями нажатие приводит к описанному результату.
- Альтернативы и отказ не приводят к неописанной смене срока, владельца или Telegram-привязки.
- Проверить основной сценарий и перечисленные ошибки на тестовых данных; персональные секреты не включать в отчёты.

Критерии выше — план проверки этого UC. В данной задаче сверяется документация; новый прогон продуктовых тестов по каждому UC не заявляется. Связанные существующие проверки: [карта требований SDD](../../sdd/SPEC.md).
